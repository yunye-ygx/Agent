# NX200 网络故障指南

doc_id: NET-NX200
状态：当前；发布日期：2026-09-01；适用型号：NX200；适用固件：2.0.0–2.9.x。
声明：虚构教学资料。

## NET-NX200-S1：E42 地址冲突

E42 表示检测到局域网 IP 地址冲突。先记录当前 IP、地址分配方式和错误发生时间，联系网络管理员确认是否存在重复地址。若管理员确认可更改地址，应由管理员分配未占用的地址。不能自行猜测一个空闲 IP。设备信息中的 DHCP 或静态地址只代表配置方式，不代表网络当前一定正常。

## NET-NX200-S2：恢复操作限制

E42 不应以恢复出厂设置作为第一步。网络恢复出厂设置会清除静态 IP，可能使设备失联。普通重启不清除静态 IP，但无法保证消除地址冲突。确需重置时，先由管理员确认网络配置备份及恢复方案，再交由人工支持指导执行。
