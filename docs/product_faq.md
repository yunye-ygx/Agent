# 星河云平台产品 FAQ

> 文档编号：PRODUCT-FAQ-2026-04  
> 生效日期：2026-04-10  
> 适用范围：星河云平台标准版、专业版  
> 维护部门：产品支持组

## 1. 文件导出

1.1 标准版支持 CSV 和 XLSX 导出；专业版额外支持 PDF 导出。

1.2 导出任务为异步任务。提交成功只代表任务进入队列，不代表文件已经生成。

1.3 单次导出最多包含 100000 行数据。超过上限时，应按时间范围或业务分区拆分导出。

1.4 导出任务创建后，用户可以在“任务中心”查看排队中、处理中、成功和失败状态。失败任务会展示错误码，但不会自动重复扣减导出额度。

## 2. API 访问

2.1 专业版支持 API 访问，标准版不包含 API 配额；具体配额以租户合同和控制台显示为准。

2.2 API 请求必须携带租户 ID 和访问令牌。访问令牌只允许访问创建它的租户数据。

2.3 连续 5 分钟超过租户速率限制时，服务返回 HTTP 429，并在响应头中给出建议等待秒数。

2.4 访问令牌泄露时，管理员应在控制台立即撤销旧令牌并重新生成。平台不会通过客服工单直接替客户提供完整令牌内容。

## 3. 数据保留

3.1 标准版操作日志保留 30 天，专业版操作日志保留 180 天。

3.2 已删除的业务数据进入回收站并保留 7 天；超过 7 天后由系统异步清理，无法保证恢复。

3.3 数据导出文件默认保留 24 小时，超过时间后下载链接失效，但不会影响源数据。

## 4. 版本与兼容性

4.1 当前 FAQ 针对平台版本 2026.04。旧版本行为可能不同，回答版本相关问题时必须先确认租户当前版本。

4.2 API v1 计划在 2027-01-01 停止新增功能，但截至本文件生效日仍继续提供维护；迁移到 API v2 的具体时间以官方公告为准。

4.3 本文没有说明的计费、合规、数据跨境或定制开发问题，客服助手必须说明知识库资料不足，并转交对应团队，不能自行承诺。

## 5. 常见误解

5.1 “提交导出任务成功”不等于“导出文件已生成”。应以任务状态为“成功”为准。

5.2 “专业版支持 PDF”不等于所有报表都支持 PDF；若具体报表页面没有 PDF 选项，应以页面能力为准。

5.3 “日志保留 180 天”只适用于专业版操作日志，不适用于导出文件或已删除业务数据。
