# 受控知识库文档

这组文档用于本地 RAG 学习和检索实验，不代表任何真实公司的制度。

## 文档约定

- 文档均为 Markdown，便于第一版离线处理链路读取。
- 每份文档包含标题、适用范围、生效日期和条款编号，后续 Chunk 需要保留这些元数据。
- `leave_policy.md` 与 `expense_policy.md` 使用“北辰科技”作为虚构公司名称。
- `ticket_process.md` 与 `product_faq.md` 使用“星河云平台”作为虚构产品名称。
- 文档中的金额、时间和状态是刻意设计的测试数据，请不要把不同文档中的规则自动合并。

## 建议测试问题

1. 北辰科技的年假能否折现？
2. 试用期员工可以申请年假吗？
3. 出差住宿超过标准后还能报销吗？
4. 交通费没有发票怎么办？
5. 工单的 P1 和 P2 响应时限分别是多少？
6. 工单已经关闭后还能重新打开吗？
7. 星河云平台支持哪些导出格式？
8. 知识库中没有提到的产品能力应该如何回答？
9. “周末加班能换调休吗？”（需要同时检索年假和加班相关条款；当前文档只覆盖年假，应该拒答或说明资料不足。）
10. “所有费用都可以先报销后补发票吗？”（不能把差旅和普通采购规则混为一谈。）

## 版本与冲突实验

第一版只使用当前文件。后续可以复制一份文档并修改生效日期或某一条款，测试：

- 元数据过滤是否能选中指定版本；
- 新旧文档同时存在时，系统是否会引用过期规则；
- 回答是否能展示文件名、章节和条款编号。
